# Online Shop Data Model

Conceptual, logical and physical data model for an online shop (inventory + orders).

- `modelo_conceptual.png` -> E/R diagram
- `modelo_logico.png` -> relational model (tables, PK, FK)
- `tienda.sql` -> MySQL script with the tables, some test data and two queries

## Run it
```bash
mysql -u root -p < tienda.sql
```
